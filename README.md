# Pedidos de Apoio

Aplicação Java Web para registo e validação de pedidos de apoio informático escolar.

## Tecnologias
- Java 17
- Jakarta Servlet 6
- JSP
- HTML5
- CSS3
- Maven
- Jetty 12

## Funcionalidades
- Registo de pedidos de apoio.
- Validação da sala.
- Validação do tipo de avaria.
- Validação da descrição.
- Apresentação de mensagens de erro.
- Confirmação dos pedidos válidos.
